# 🚀 Early Network Fault Prediction using Temporal Machine Learning

## 📌 Overview
This project predicts network faults in routers and switches using Machine Learning and LSTM (Temporal Learning).

## 🧠 Features
- Real-time network monitoring
- Fault prediction using ML (Random Forest)
- Temporal prediction using LSTM
- Visualization of latency and packet loss
- Streamlit dashboard

## 🏗️ Architecture
Routers/Switches → Network Data → ML Model → Prediction

## 📊 Technologies Used
- Python
- Scikit-learn
- TensorFlow (LSTM)
- Streamlit
- Matplotlib

## 🔍 How It Works
1. Collect network metrics (latency, packet loss)
2. Train ML model
3. Predict faults
4. Display results via dashboard

## ▶️ How to Run

### Install dependencies

### Run ML model

### Run LSTM

### Run Dashboard
